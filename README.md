# Dytallix Faucet

Testnet faucet for Dytallix — dispenses DGT and DRT to addresses on request.

## Status

Under construction. The faucet API is called by the dytallix-sdk FaucetClient.

## Endpoints

Testnet faucet: https://faucet.dytallix.com
